# Рецепт SatDump +lab (2.0.0~alpha+git20260929+lab1)

Стан: рецепт збирача +lab (схема 2 `build_recipe`, важкий job `lab-heavy` у `sr-rx-packages.yml`, W2 SW-SATDUMP). Запис збирання, який пише CI, має статус **CI_BUILT_UNREVIEWED**: це доказ CI на arm64, а не рецензія збірки; `verify_build` лишається OPEN, доки рецензент не перевірить маніфест. Важкий job іде на push, що змінює цей каталог (або `build_recipe.py`, `lab_build.py`, `vendor_patch.py`, `patches/target-hashes.json`, сам workflow, запис `satdump` у lock), і на коміт із `[lab-build-all]`; номери прогонів записує крок доказів (INT/EVID), не цей файл.

SatDump розповсюджується за GPL-3.0 (upstream `LICENSE`, blob f288702d2fa16d3cdf0035b15a9fcbc552cd88e7). Патчі — похідні зміни за тією самою ліцензією.

Порядок у збирачі (`build_recipe.py`, у chroot без мережі): SHA256 архіву → розпакування → хук `verify-source` → `git apply` 0001–0005 (перед кожним — SHA256 патча і blob цілей) → `cmake -G Ninja` з усіма опціями й змінними рецепта → перевірка, що кожну обчислену опцію задано явно → `cmake --build --parallel` → `cmake --install` у DESTDIR → хук `package` → перевірки рецепта → один `.deb` через `dpkg-deb` з `SOURCE_DATE_EPOCH` архіву. `libsatdump_core.so` і плагіни мають SONAME без версії: `dpkg-shlibdeps` пропускає такі бібліотеки (dpkg 1.22.6, `scripts/dpkg-shlibdeps.pl`, прочитано 07.11.2026), тож Depends дають лише бібліотеки noble. Збирання повторюється двічі в тих самих шляхах (`reproducible`).

Запис встановлення. `record_digests` (SHA256 ELF, `libsatdump_core.so`, плагінів, конвеєрів, конфігу, дайджест дерева `share/satdump/resources` і SHA256 цього `recipe.json`) збирач копіює в запис збирання, а `installation_template` у `satdump.package-hook.json` (артефакти `lab-out-satdump` і `lab-packages-ci`) — це запис `decoder_policy.load_satdump_installation` поле в поле. Його `evidence_id` — заповнювач, який `decoder_policy` відхиляє (`INSTALLATION_VERSION_OR_PROVENANCE_UNVERIFIED`): адміністратор вписує рецензований доказ і ставить файл root-owned (≤8 KiB) при введенні в експлуатацію; у Git прийнятого запису немає ([DECODERS](../../../software/DECODERS.md)).

Рішення (W2 SW-SATDUMP, [build/15](../../../build/15-rishennia-komplektu.md)): без `libarmadillo-dev` (на 1aedd60 `find_package(Armadillo)` необов'язковий); один пакет без `-dev`; `PLUGIN_SIMD_NEON` вимкнено, бо `simd_neon` немає в алоу-листі плагінів STACK — вмикати лише окремим рішенням після заміру CPU на Q6A; фікстура LRPT — лише запис із зазначеною ліцензією або стендовий запис власника.
