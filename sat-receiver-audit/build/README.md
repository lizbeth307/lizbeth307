# Пакет збирання — супутниковий приймач лише на прийом і портативна радіолабораторія

Архівна версія пакета: v2, 18.10.2026. Опис нижче збережено для простежуваності; чинні зміни визначає [v2.1](12-revision-v2.1.md), актуальні графи та review у `../design/`.

**Статус:** теоретичний проєкт — перевірити на стенді. Деталі, рейки, піни й процедури звірено з повторним аудитом (P4), рішеннями щодо аналогів (P5) і багатьма перевірками. Але жодна збірка ще не вимірювалася. Усе, що позначено «модель», «TBD» або «не перевірено», треба виміряти на стенді (див. `09-testy.md`, STACK.md §8, §8.1, §8.2).

## Правила, які діють для всього пакета
- Лише прийом в ефірі. Генератори, VNA і шумове джерело підключаються тільки кондуктивно, у навантаження або DUT і ніколи в антену.
- Без декодування приватного змісту. Без трактів під військовий зв'язок.
- Без рамкових антен і H-field зондів, без тарілок. Антени — патч/чип або складані частини ≈20–23 см.
- Місце визначається з GNSS, таблиць міст немає.
- LimeSDR Micro M.2 входить у збірку за замовчуванням, його TX заблоковано.
