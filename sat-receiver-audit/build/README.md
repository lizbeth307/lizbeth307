# Пакет збирання — супутниковий приймач лише на прийом і портативна радіолабораторія

Версія: v2, 18.10.2026. Джерело істини — [../STACK.md](../STACK.md) (стек v2). Якщо файл пакета розходиться зі STACK.md, правильний STACK.md.

**Статус:** теоретично перевірений проєкт. Деталі, рейки, піни й процедури звірено з повторним аудитом (P4), рішеннями щодо аналогів (P5) і багатьма перевірками. Але жодна збірка ще не вимірювалася. Усе, що позначено «модель», «TBD» або «не перевірено», треба виміряти на стенді (див. `09-testy.md`, STACK.md §8, §8.1, §8.2).

## Правила, які діють для всього пакета
- Лише прийом в ефірі. Генератори, VNA і шумове джерело підключаються тільки кондуктивно, у навантаження або DUT і ніколи в антену.
- Без декодування приватного змісту. Без трактів під військовий зв'язок.
- Без рамкових антен і H-field зондів, без тарілок. Антени — патч/чип або складані частини ≈20–23 см.
- Місце визначається з GNSS, таблиць міст немає.
- LimeSDR Micro M.2 входить у збірку за замовчуванням, його TX заблоковано.

## Порядок роботи
1. **Купити** за `10-bom.md` і STACK.md §9.1. Спершу позиції з довгим терміном поставки й ризиком наявності. Рішення щодо Lime треба ухвалити до 1.12.2026: Crowd Supply повертає гроші повністю лише до відвантаження 15.12.2026.
2. **Приймати** кожну деталь на прибутті за `09-testy.md`, поки діє вікно повернення.
3. **Зібрати** за `08-zbyrannia.md`, звіряючись з `02`, `03`, `04` і `05`. Силову плату паяти лише оплавленням. Перше ввімкнення — від джерела з обмеженням струму.
4. **Встановити ПЗ** за `07-pz-vstanovlennia.md`. Пройти CI-перевірки відсутності TX і приватних шляхів.
5. **Тестувати** за `09-testy.md` (ворота W1–2, A/B-матриця завад, термопрогін, приймання Lime) і в полі.
