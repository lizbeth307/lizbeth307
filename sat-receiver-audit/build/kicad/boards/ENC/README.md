# Дочірня плата енкодера ENC, 24 × 24 мм — W2 PCB-SB1

**Статус: `SB1_ROUTED_NOT_FOR_FABRICATION`.** Один дизайн для ENC301 (головний енкодер, екземпляр ENCM) і ENC302 (гучність, ENCV) плюс одна запасна плата — 3 плати. Плату розведено в `sr-rx-pcb` (KiCad 10.0.7, Freerouting 2.5.0; прогін розведення 42421671986 на 87d332d): DRC — помилок 0, непідключених 0, 7 переглянутих попереджень `silk_over_copper` (контур PEC11R перетинає власні площадки), `ignored_checks` порожній; аудит source-pad — 0 для ENCM і ENCV; аудит межі — `provisional: header ref pending GR-3` (нижче). Це результат CI/моделі, а не випуск у виробництво й не апаратний PASS.

- **Від пілота W2 PCB-PIPE** без змін лишилися контур і два отвори з контракту механіки, PEC11R на (12, 12) з кутом 90, скриптовий заблокований зв'язок GND J1.1 → ENC.C на B.Cu і заливки GND; S1/S2 кнопки несуть кола графа (E3_ENCx_PRESS_EXT і GND, W2 GR-1).
- **J1 — площадка для дротів, роз'єм не ставиться.** Кінці S37/S38 — чотири дроти 26 AWG (Alpha Wire 5853), впаяні в 4-контактну площадку з кроком 2.0 мм (KiCad PinHeader_1x04_P2.00mm_Vertical: отвір 0.8, площадка 1.35) у крайовій зоні зліва; порядок GND, A, B, PRESS — як у J316/J317 на CTRL, де стоїть корпус PH 4. Рішення «Роз'єм плати ENC (W2 PCB-SB1)», build/15: жоден корпус JST PH не вміщується поруч із PEC11R на 24 × 24.
