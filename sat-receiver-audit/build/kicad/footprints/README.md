# Project footprint library (KiCad 10.0.7)

Generated by `tools/build_parts.py` from `design/parts/parts.json`; do not edit by hand. 64 footprints carry 675 footprint assignments of the schematic graphs design/E1..E5.json; `manifest.json` lists each file with its SHA256, pad names and refs.

- 49 official KiCad 10.0.7 footprints, byte-for-byte unmodified, in 17 libraries (Capacitor_SMD, Capacitor_THT, Connector_Coaxial, Connector_JST, Connector_Molex, Diode_SMD, Fuse, Inductor_SMD, LED_THT, Module, NetTie, Package_DFN_QFN, Package_SO, Package_SON, Package_TO_SOT_SMD, Resistor_SMD, TestPoint). Source: https://gitlab.com/kicad/libraries/kicad-footprints/-/tree/10.0.7 (the first 17 came from the PPA package `kicad-footprints_10.0.7~ubuntu24.04.1_all.deb`, SHA256 a1c25a690348180d572b73496668cffafdaecf284d6555279fa89d5e4fefa46c, which carries the same files). The parts workflow compares every one of them with the library inside the kicad/kicad:10.0.7 image.
- 10 custom footprints in `SR_RX_Custom.pretty`, written by `tools/make_footprints.py` from the manufacturer land pattern named in `SR_RX_Custom.pretty/provenance.json` (URL, drawing, page, read date).
- 5 derived footprints in `SR_RX_Custom.pretty`: an official footprint with unchanged geometry whose pad numbers are renamed to the graph pin names (A/K, CENTER/SHIELD, EPAD, SWD pads); the source SHA256 is in provenance.json.

The project fp-lib-table uses ${KIPRJMOD} relative paths. See LICENSE.md for the KiCad library licence. No 3D models are committed. A footprint here is a layout input, not a fabrication release: custom land patterns still need review against the part drawing before an order.
