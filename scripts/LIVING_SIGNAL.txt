Living Signal — головна візія
=============================

Байт-потік, що сам відновлює структуру і проростає вглиб через шари
протоколу — без імен бекенду, без ручних dissector’ів.

Шлях (вже працює на PCAPdroid MITM + Termux)
--------------------------------------------
  PCAP bytes
    → TCP reassembly
    → TLS records / handshake peel (SNI, ALPN)
    → NSS keylog decrypt (AES-GCM, SHA256/384)
    → HTTP/2 frames (HPACK headers)
    → DATA decompress (gzip / br)
    → HTML title / JSON API schema
    → protobuf / MessagePack peel (якщо binary API)
    → signal_report.json

Компоненти
----------
  protocol_ast/signal.py       — Signal.propagate (ядро)
  protocol_ast/splitters.py    — універсальні peel’ери
  protocol_ast/tls_keylog.py   — SSLKEYLOGFILE decrypt
  protocol_ast/http2.py        — frames + HPACK + br/gzip
  protocol_ast/json_api.py     — schema merge для JSON API
  protocol_ast/binary_peel.py  — protobuf wire + msgpack
  protocol_ast/probe_loop.py   — adaptive active probe → Signal
  protocol_ast/stream_agent.py — інкрементальний агент по pcap
  analyze_pcap.py              — Termux single-file UI (v3.8.0)
  probe_network.py             — зонд + loop + stream + watch

Команди (телефон)
-----------------
  export PYTHONPATH=$HOME

  # offline living signal (після MITM capture)
  python3 ~/analyze_pcap.py ~/downloads/cap.pcap \
    --signal --flow TCP:443 --keylog auto

  # incremental events
  python3 ~/analyze_pcap.py ~/downloads/cap.pcap --stream --keylog auto

  # adaptive probe loop (без pcap теж)
  python3 ~/probe_network.py --loop 3 --no-capture

  # watch growing PCAPdroid dump
  python3 ~/probe_network.py --watch ~/storage/downloads/PCAPdroid/foo.pcap --keylog auto

Desktop
-------
  python3 discover_protocol_ast.py signal capture.pcap --keylog auto
